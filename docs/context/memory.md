# Memory — Architecture & Decisions

- # decision: All market data (xlsx/csv) gitignored — repo is code-only, safe for public hosting.
- # decision: Strategy universe segments = World / DM / EM (Asia, Europe, LatAm as secondary regions).
- # decision: Score pipeline = raw factor -> 4 metrics (expanding zscore, abs pct, relative rank, 63d delta pct) -> weighted factor score -> category aggregate -> composite -> cross-sectional 0-1 normalization.
- # decision: Validation standard = Deflated Sharpe, PSR, anchored walk-forward, Monte-Carlo random-selection null, equal-weight buy-and-hold null (adopted from docs/superpowers/plans/2026-06-07 methodology; must be ported to this codebase).
- # decision: docs/superpowers plans pre-2026-06 reference a `momentum_strategy` package from another repo — methodology reusable, file paths are not.
- # decision: Package root is `country_rotation/` (v0.2.0); config entry-point is `load_config(path) -> PlatformConfig` (frozen dataclasses); canonical defaults live in `configs/default.json`.
- # decision: All yield/margin/reconstruction divisions in processing.py route through `_safe_div` (non-positive denominator -> NaN) — deliberate D8 fix over legacy raw division; consensus growth ratios are NOT guarded (legacy parity, forward multiples can be negative).
- # decision: Look-ahead detection uses input perturbation (multiply + shift future rows by perturb_scale); any output difference at dates <= cutoff indicates leakage. fillna(-9e9) before allclose so NaN-matching is consistent.
- # decision: Perturbation must fillna(0.0) before scaling future NaNs so NaN gaps after cutoff are forced to a sentinel and not silently preserved; column-set mismatch between base and perturbed outputs is itself treated as dirty.
- # decision: Pure transform functions do NOT apply .iloc[window:] slicing — they return full aligned DataFrames; callers decide which rows to consume (legacy class sliced for its own downstream use only).
- # decision: absolute_percentile uses method='min' (fraction <= self); delta_percentile uses method='average'; both match legacy FactorTransformer.py exactly.
- # decision: composite contributions stored as {category: DataFrame} absolute weight×score (not legacy proportions); rebase scales by norm/composite so sum of rebased contributions == normalized score.
- # decision: IC date grid = scores.index[::-periodicity] then sorted (legacy reverse-sampling); signal pairs grid[i] with forward return grid[i]→grid[i+1]; relative method diffs sampled frame and drops first row — exact legacy parity.
- # decision: metrics.summary() annualises via calendar days (365/days) not trading days; vol = std*sqrt(ppy); Sharpe has no risk-free rate — matching legacy backtest.py exactly.
- # decision: backtest/engine.py Engine is a verbatim math port of legacy Backtest (blend mode = bitwise parity, smoke-checked 0.0 diff); active_return = GROSS - bmk (legacy ~:229), historical_weights indexed by d_ret, first-period turnover = 1 - bmk_weight.
- # decision: Engine 'active' mode = no benchmark row, bmk_weight ignored for construction; period_results still reports bmk_return/active_return; cfg.execution_lag_days ignored until Plan B (parity first).
- # decision: Engine period_results uses snake_case columns (portfolio_return_gross/net, bmk_return, active_return, turnover, transaction_cost); legacy dict keys were returns/returns_net/benchmark_returns/active_return/turnover/transaction_costs.
- # decision: cluster_factors() public API defaults to linkage_method='average'; legacy FactorTransformer.py defaulted to 'ward' (line 769) — callers must pass 'ward' explicitly to match legacy exactly.
- # decision: equal_weight_buy_hold() drops columns with any NaN over the window (not just all-NaN); no rebalancing — rebases each column to 1.0 at first date then takes mean.
- # decision: weighted_metric_average is strict — every metric key present in factor_results must have an explicit metric_weights entry, else ValueError (no silent implicit weight 1.0).
- # decision: build_scores.py uses transforms.transform_factor metric keys (zscore, absolute_pct, relative_rank, delta_pct) as the canonical metric-weight vocabulary.
- # decision: read_inputs raises FileNotFoundError on missing folder; library code uses warnings.warn, never print.
- # decision: validation/statistics.py — equity-curve functions (sharpe_significance, PSR, DSR, bootstrap_ci) do pct_change().dropna() internally; newey_west_tstat takes a return series (pd.Series) directly. PSR uses non-excess kurtosis γ4 (fisher=False, Normal=3). DSR expected_max has no mean term (null E[SR]=0); N<=1 → 0.0. SharpeSignificance has sharpe_ann = sharpe_daily*sqrt(252).
- # decision: validation/protocols.py walk-forward boundary semantics — burn-in = max(2*periodicity, 126) usable dates reserved for fold-1 training; fold k IS = data strictly BEFORE segment k start; OOS = period returns with d_ret inside [seg_start, seg_end] from a run truncated at seg_end (boundary-straddling periods count as OOS since selection used only pre-segment data); candidate dedup by full BacktestConfig field tuple; MC null p-value uses add-one smoothing (null>=actual+1)/(n+1) with NaN sharpes treated as 0.
- # decision: protocols.py Sharpe figures come from sharpe_significance on equity_curve of PERIOD net returns — per-period units annualized with sqrt(252); comparable scores across configs/folds/sims, not standalone annualized estimates.
- # decision: selection/walkforward.py — lockbox = LAST floor(lockbox_frac*n) common dates, never read by screen_factors; per-factor p = one-sided t on FULL per-period IC series (df=n_ic_obs-1, Grinold-Kahn approach); folds still computed for sign-consistency regime-robustness gate only; zero-std ic-series splits by sign; BH q-values threshold-independent; weak label = |t_series| < 3 (HLZ); FactorScreenResult gains series_t and n_ic_obs fields; MIN_IC_OBS=8 degenerate guard.
- # decision: screen_factors min_mean_ic parameter (default 0.0) tightens gate (a): mean of fold ICs must exceed min_mean_ic (not just > 0); backward compatible.
- # decision: validation/scorecard.py compute_validation runs Engine once; EQW null via equal_weight_buy_hold on country_cols (scores∩prices, exclude bmk); NaN-safe verdict checks with _safe_ge/_safe_le/_safe_gt; trial_sharpes for DSR = sweep table sharpe_daily (NaN rows dropped); DSR/WFE/MC → no_overfitting; stability → param_stable; t/PSR/bootstrap/NW → statistically_significant.
- # decision: Classification.xlsx 'regiones' sheet contains 6 Region pseudo-rows (DM/EM/Europe/Asia/World/LatAm) — universe extraction MUST filter Type=='Country'; raw Price.xlsx carries index columns with the same names.
- # decision: scripts/research_run.py benchmark = equal-weight average of universe price relatives, column named after the segment (matches the EQW null in validation; raw index columns are external levels outside the classified universe); cfg = active mode, bmk_weight=0, relative selection.
- # decision: research_run.py treats kept=0 from screening as a first-class outcome — verdict_{segment}.json always written (overall=false, stats=null), composite/validation/report skipped, exit 0; no threshold fiddling to manufacture survivors.
- # decision: World @63d screening result (2010-2025, 45 candidates): nothing passes BH-FDR q=0.10 over the full family; binding gate is FDR (best raw p: AssetsEquity 0.003 → q 0.137). Policy options if revisited: per-category BH families, fdr_q, screening horizon — requires explicit decision, not a code fix.
- # decision: reporting/report.py uses matplotlib Agg backend (set before pyplot import); all figure functions return base64 PNG or None (tolerate missing/empty input); build_report orchestrator runs Engine + EQW + daily metrics (ppy=252) + period metrics (ppy=252/periodicity) + IC per method + optional contributions + optional ValidationReport; HTML rendered via render_html with inline CSS.
- # decision: Cap_Tilt weighting (Engine base_weights kwarg, active mode only) = cap-base asof d_sel (valid score+price names, renormalized) + total_under/N on top-N, - min(active_share/N, base_i) on bottom-N from the SAME selection signal (relative = score change; absolute = score level, bottom mirrors threshold side as N lowest levels, N = count above threshold); missing base row -> hold previous weights; cfg.active_share default 0.30; base_weights threaded through protocols/scorecard/report with walk-forward slicing identical to prices.
- # decision: reporting/dashboard.py = multi-strategy shell over report.py primitives — build_strategy_pane(scores, prices_with_bmk, cfg, base_weights, verdict_json, contributions) re-runs the Engine per strategy and rebuilds the scorecard from the serialized verdict (not a live ValidationReport); render_dashboard uses pane ids '{segment}-{strategy_key}', vanilla JS, default strategy cap_tilt; scripts/build_dashboard.py reuses research_run.ingest/build_factor_scores/select_prior_factors(vm)/build_composite once per segment and only swaps engine configs across the 3 strategies (cap_tilt/eqw_active/blend50, vendor cap index bmk).
- # decision: Engine selection_criteria gains 'top_n_level' (additive, non-legacy) = top N by score LEVEL at d_sel (scores.loc[d_sel].dropna().nlargest(N)) — canonical AMP-2013 selection; under Cap_Tilt the bottom-N underweights come from the SAME level signal; 'absolute'/'relative' untouched (parity green).
- # decision: scripts/spec_tournament.py = pre-registered 6-spec signal family (blend/AMP-E-P/AMP-BP/mom x level/change), IC method matched to traded signal (relative for change-selection, absolute for level), screen window = first 80% of common dates (walkforward convention), BH-FDR across the 6 specs per segment, winner = best q (tie: higher mean IC), one-shot lockbox confirm — re-running after changing the family is lockbox burn.
